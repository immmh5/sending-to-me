# 📥 أرسل لنفسي

موقع شخصي بسيط ترسل فيه لنفسك **نصوص وصور وملفات وفيديو وصوت** من أي جهاز (جوال أو كمبيوتر).

- ❌ بدون نظام حسابات
- 🔑 كلمة مرور واحدة فقط عند الدخول — وأي شخص يعرفها يشوف كل شيء
- 🖼️ الصور والفيديو تظهر مباشرة، والملفات تتحمّل بضغطة
- 🔄 تقدر تغيّر كلمة المرور من داخل الموقع وقت ما تبغى

---

## التشغيل

المطلوب فقط **Node.js** (أي إصدار حديث):

```bash
cd send-to-self
node server.js
```

ثم افتح المتصفح على: `http://localhost:3000`

أو استخدم سكربت التشغيل:

```bash
./start.sh
```

---

## كلمة المرور

- **كلمة المرور الافتراضية: `12345`**
- غيّرها فوراً من داخل الموقع: زر **🔑 تغيير كلمة المرور** (تحتاج تكتب الكلمة الحالية).
- تقدر تغيّرها كمان يدوياً من ملف `data/config.json` (حقل `passwordHash` مشفّر — الأفضل تغييرها من الموقع نفسه).

> ملاحظة: أي شخص يعرف كلمة المرور يقدر يغيّرها أو يحذف كل شيء. هذا هو المقصود من "بدون حسابات".

---

## وين تتخزن الملفات؟

كل شيء في مجلد `data/`:

- `data/items.json` → قائمة كل ما أُرسل (نص/ملف)
- `data/uploads/` → الملفات الفعلية
- `data/config.json` → كلمة المرور المشفّرة + مفتاح الجلسات

احذف مجلد `data/` عشان ترجع الوضع الافتراضي.

---

## النشر على الإنترنت (عشان ترسل من جوالك من أي مكان)

1. **سيرفر خاص (VPS)** — ارفع المجلد وشغّل:
   ```bash
   npm i -g pm2
   pm2 start server.js --name send-to-self
   ```
   ويفضّل تحط خلفه HTTPS (Caddy أو Nginx).

2. **استضافة مجانية**: Render أو Railway أو Fly.io — ارفع المجلد، حدّد أمر التشغيل `node server.js`.

3. **من جوالك**: افتح الرابط وأضِفه للشاشة الرئيسية (Add to Home Screen) عشان يصير مثل تطبيق.

> ملاحظة أمان: بدون HTTPS كلمة المرور والملفات تنرسل نص مفتوح، فالأفضل دايم تشغّله خلف HTTPS.

## الأوامر المتاحة (للمطوّر)

| الأمر | الوصف |
|---|---|
| `GET /api/health` | فحص أن السيرفر شغّال |
| `POST /api/login` | دخول بكلمة المرور |
| `GET /api/items` | قائمة كل العناصر |
| `POST /api/upload` | إرسال نص + ملفات (multipart) |
| `GET /api/file/:id` | جلب ملف (يدعم `?download=1`) |
| `DELETE /api/items/:id` | حذف عنصر |
| `DELETE /api/items` | مسح الكل |
| `POST /api/change-password` | تغيير كلمة المرور |
